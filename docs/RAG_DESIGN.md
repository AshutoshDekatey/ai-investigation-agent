# Retrieval design

Source: 24 concise current fictional policies spanning failures, finality, duplicates, refunds, chargebacks, exceptions and escalation; two expired versions and one adversarial unapproved attachment. JSON carries explicit metadata. Ingestion validates date ranges, versions and text, then creates 120-word windows with a 100-word stride. Current documents fit one window each. IDs include policy, version and offset so quotes resolve exactly.

Default encoder: Sentence Transformers `all-MiniLM-L6-v2`, immutable revision `c9745ed1d9f207416be6d2e6f8de32d1f16199bf`, CPU normalized embeddings. Pinning must be validated by successful model download in your environment; that step was blocked here. Qdrant cosine retrieval and BM25 lexical retrieval rank identical approved/date-eligible candidates. Reciprocal-rank fusion uses 1/(60+rank), then returns five documents. Metadata validation applies before either arm and excludes unapproved injection attachments. The index stores encoder identity and rejects model mismatch. Test-only embeddings use a separate collection and are explicitly labelled.

The bounded implementation scrolls at most 1,000 points and fails if the corpus exceeds that limit. It does not scale to an unbounded production corpus. Persistent Qdrant server is standard; embedded local Qdrant is for isolated tests/development. Metadata filtering is enforced through Qdrant candidate IDs plus identical lexical filtering.

Workflow decisions use deterministic authoritative record assessment. If the applicable topic's policy is absent from the top five, the outcome becomes uncertain. Natural-language-only retrieval evaluation runs independently and does not add the gold topic. Quotes are copied from retrieved chunks and verified against them, and the evaluator additionally checks original corpus text and policy validity. Unknown/unapproved documents cannot supply approved policy evidence. Approval metadata itself is trusted developer input; this is not a document-signing system.

No cross-encoder reranker is enabled. Learned retrieval measurements are unavailable due to the model-host network restriction, so no measurable reranking improvement can currently be claimed. A useful next experiment is compare vector-only, BM25-only, hybrid and reranked Recall/MRR on independently written questions. The current report measures hybrid only.
