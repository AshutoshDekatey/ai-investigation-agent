# v0.1 scope (historical, retired)

This version is no longer included in the active runtime. Use the current `payments` CLI and RUNBOOK.md. Commands below describe the historical release only.

Small synthetic payment investigation demo: four records, three fictional policies, five evaluation cases including a missing ID. Supports settled, failed, pending and unknown records. Each output cites transaction evidence and applicable policy, a recommendation, uncertainty and a mandatory human-review flag.

Offline defaults use deterministic concept embeddings and status rules. Optional sentence-transformer and OpenAI integrations are separately configured. No live bank connection, payment action, refund, retry, authentication service, persistent case history, production policy interpretation or financial advice is implemented.

Validation: run `uv run --frozen --extra dev pytest -q`; this executes the evaluation cases, retrieval ranking, immutability, policy-evidence fallback, fake LLM success/error paths, CLI JSON and paid-mode guard. Live LLM behavior and learned embedding quality require separate evaluation; offline tests do not establish either.
