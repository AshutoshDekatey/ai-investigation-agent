# v0.2 — payments investigation platform

Replaces the v0.1 runtime while preserving its Git history and adds learned-embedding default retrieval, persistent Qdrant + BM25 hybrid search, explicit policy metadata and versions, locally hosted bank tools, settlement reconciliation, a nine-node checkpointed LangGraph, PostgreSQL reports, authenticated FastAPI, CLI, Docker Compose, 60 regression cases and recorded evaluation.

Validated infrastructure uses an explicitly labelled test encoder because pretrained model download was blocked. The user later reported downloading learned weights and successfully running one live OpenAI summary; provenance and usage are recorded in EVIDENCE.md. Learned retrieval quality, broader live-LLM accuracy and optional LangSmith tracing remain unverified. Cross-encoder reranking and independent semantic judging are deferred. No financial execution or production banking access is implemented. See EVIDENCE.md for exact results and RUNBOOK.md for reproduction.
